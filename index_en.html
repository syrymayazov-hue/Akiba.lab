The Yokengan Project

Yokengan is a wearable hardware solution created by the Akiba-lab engineering laboratory. Our goal is to create an accessible smart glasses system featuring a real-time HUD (Heads-Up Display).

The product solves problems in the B2B sector (navigation and inspection for logistics and engineers) and opens new horizons in B2C, acting as an uncompromising intelligent assistant for the visually impaired.

Final Architecture

NPU Camera Module

Moving heavy machine vision calculations directly into the camera module featuring a built-in neural accelerator.

  • + The system remains cold.
  • + High response speed.
  • + 100% autonomy.

Vision

Standard Camera Module — capturing the environment in real-time for subsequent object detection.

Display

0.91" / 0.96" OLED Matrix — energy-efficient HUD interface, connected via I2C for text projection.

AI Brain

Google Gemini API Integration via Wi-Fi for instant generation of complex, contextual descriptions of detected objects.

Chassis

Custom frame and enclosures, designed and 3D-printed at Akiba-lab using Bambu Lab and Creality printers.

How It Works

01

Scan

The NPU-camera scans the environment and identifies the object via hardware processing.

02

Trigger

A physical button on the glasses frame or an auto-timer captures the needed frame and transmits it via a mobile hotspot.

03

Analyze

The Gemini neural network instantly analyzes the data and generates an accurate description (e.g., car brand or sign text).

04

Project

The text is projected directly into the user's eye through an OLED matrix.
